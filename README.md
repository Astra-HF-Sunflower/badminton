# 火柴人羽毛球 · Stickman Badminton 🏸

一个用 **React 19 + TypeScript + Canvas + Vite** 写的网页羽毛球游戏：火柴人角色、实时物理、十二种击球、三种场地、三种玩法（含恶搞模式）、合成音效与背景音乐，纯前端、零后端。

## 开始玩

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 打包成单文件 dist/index.html
npm run preview  # 预览打包结果
```

## 玩法

- **三种玩法模式**
  - 普通模式：高远球 · 杀球 · 平抽球 · 挑球，4 种基础击球
  - 专业模式：九种进阶击球，增加吊球、搓球、弹击、跳杀、劈吊
  - 恶搞模式（Chaos）：不讲武德，得分翻倍
    - **没有规则**：两侧空气墙打通 —— 球从左边飞出去就从右边飞回来；也没有出界线，**落在谁半场谁丢分**，只看落地
    - **雷霆蓄力杀球**：按住 `7` 蓄力（**蓄力时照样能跑**），**松手就出手**，不用等蓄满。蓄力分四档（25% / 50% / 75% / MAX），每一档力度肉眼可见地不同：**不蓄力约 11000 px/s，满蓄力 37000+ px/s** —— 一步就跨过整个球场，球是一道残影（满蓄 MAX 额外 +3 分）
    - **超级反弹**：轰出去之后 **3 秒彻底无视物理法则** —— 不减速，弹一次反而更快、还时不时自己拐弯，3 秒后物理才回来，开始正常减速落地。这 3 秒里球依然可以被拦下来（冷却 10 秒）
    - **冲击波**：命中瞬间把对手震退好几步
- **三种场地**：小场地（网前缠斗）/ 中场地（标准）/ 大场地（跑起来）
- **四个角色**（仅 **恶搞模式** 可选，`Q` / 双人 P2 用右 Shift）
  - **世界**：时间停止 5 秒，球和对手都被冻住，你可以连续挥拍蓄力，时间恢复的瞬间全部倾泻而出
  - **新月**：30 秒重力操控。人和球、连球网一起飘上天，**技能键循环切换重力 ×0 / ×1 / ×5 / ×8 / ×10**（×0 完全失重、×10 直接砸下来）；**挥拍能推着自己飘向想要的方向**
  - **天堂制造**：30 秒时间加速，再按一次切换 ×2 / ×4 / ×5；**只加速你自己**——移动更快、挥拍没有前摇后摇（差不多一帧就打完），自己打出去的球才会变快，对手飞过来的球速度不变
  - **无名**：没有技能，纯靠手法
- **两种对局模式**：单人挑战电脑（轻松 / 标准 / 地狱）· 同一键盘双人对战
- **目标分数**：11 / 21 / 31 分
- **手感**：完美击球额外 ＋1 分；出界、触网、未过网对手得分
- **实时数据**：每个球员头顶显示本局出招次数与各招式的发动比例

## 操作

| 操作 | 单人 / 双人 P1 | 双人 P2 |
| --- | --- | --- |
| 移动 | `A` `D`（或 `←` `→`） | `←` `→` |
| 跳跃 | `W` / `空格`（或 `↑` / 小键盘 `0`） | `↑` / 小键盘 `0` |
| 击球 | 小键盘 `7 8 9 / 4 5 6 / 1 2 3`，或 `U I O / J K L / M , .` | 小键盘 |
| 角色技能（仅恶搞模式） | `Q` | `右 Shift` |
| 接球 | `C` | 小键盘 `Enter` |
| 暂停 | `Esc` / `P` | |

普通模式只用九宫格左上 2×2（`7 8 / 4 5`），升级到专业模式不用重新记键位；恶搞模式会把九宫格重新排一遍（`7` 雷霆杀球、`9` 超级反弹、`4` 冲击波……）。**角色技能是恶搞模式专属**，普通 / 专业模式下想选角色也选不了。

**接球**（`C` / 小键盘 `Enter`，三种玩法都能用）：球必须真的碰到**手**（头、身上都不算）且球速不快，才能把球接住改成自己发球；条件不满足会 MISS 并进入 0.5 秒硬直。

## 目录结构

```
index.html
src/
  main.tsx, App.tsx, index.css
  components/       菜单、游戏视图、键位图、触屏控件
  game/
    engine.ts       主循环：输入 → 物理 → 判定 → 特效 → 渲染
    physics.ts      羽毛球飞行（重力 + 二次空气阻力，120Hz 固定步长；暴力弹道求解）
    court.ts        场地大小（小 / 中 / 大），玩家范围与落点随之缩放
    ai.ts           电脑对手：预测落点 → 跑位 → 蓄力 / 松手 / 提前挥拍
    player.ts       角色移动、挥拍、击球判定
    swings.ts       每种击球的挥拍关键帧
    shots.ts        击球数据表 + 玩法模式配置
    characters.ts   角色与技能（时停 / 失重 / 时间加速）
    audio.ts        WebAudio 实时合成音效
    bgm.ts          背景音乐（内置合成曲 + 自定义曲目注册表）
    render/         Canvas 渲染：背景、火柴人、HUD、场景
public/bgm/         放自己的 mp3（见该目录 README）
```

## 加自己的背景音乐

把音频放进 `public/bgm/`，再在 `src/game/bgm.ts` 的 `BGM_TRACKS` 里加一行：

```ts
{ id: 'rally', title: '激战', sub: '自定义 · mp3', kind: 'file', src: '/bgm/rally.mp3', volume: 0.6 }
```

菜单的「背景音乐」会自动多出这个选项，UI 无需改动。
